# بوت واتساب + Gemini (نسخة الهاتف)

## الملفات
- `bot.js`: البوت وخادم لوحة التحكم.
- `panel.html`: لوحة التحكم العربية.
- `package.json`: المكتبات المطلوبة.

## إعدادات الاستضافة (Environment Variables / Secrets)
أضف هذه القيم في إعدادات المشروع السرية:
- `GEMINI_API_KEY`: مفتاحك من Google AI Studio (لا تضعه داخل الكود ولا ترسله لأحد).
- `PANEL_PASS`: كلمة سر طويلة وخاصة بلوحة التحكم.
- `GEMINI_MODEL`: اختياري، الافتراضي `gemini-3.8-flash`.
- `HOST`: `0.0.0.0` (مضبوطة افتراضياً).
- `PORT`: يحدده مزود الاستضافة عادةً.

## التشغيل
- Runtime: Node.js 20 أو أحدث.
- Build command: `npm install`
- Start command: `npm start`
- يجب أن تدعم الاستضافة متصفح Chromium/Puppeteer وأن تحفظ مجلد جلسة WhatsApp (`.wwebjs_auth`) وملفات البيانات بين عمليات إعادة التشغيل.

## الربط
1. افتح رابط التطبيق المنشور.
2. من لوحة التحكم، انتظر ظهور QR.
3. في واتساب على هاتفك: الأجهزة المرتبطة > ربط جهاز، ثم امسح QR.
4. لا تشارك رابط اللوحة أو كلمة سرها.
5. اختبر أولاً برقم منفصل/تجريبي.

## مهم قبل النشر
استضافة مجانية كثيرة تنام بعد الخمول أو تمسح الملفات المحلية. إذا ضاع مجلد `.wwebjs_auth` سيطلب البوت ربط QR من جديد. لا تعتبر أي استضافة مجانية مناسبة قبل التأكد من استمرار الخدمة والتخزين الدائم ودعم Chromium. قد تكون هناك قيود أو رسوم على Gemini API أو الاستضافة، حتى إن كانت هناك حصة مجانية. راجع حدود الاستخدام في Google AI Studio.

هذه أداة غير رسمية تعتمد WhatsApp Web؛ قد تتغير أو تتوقف، وقد يؤدي استخدامها إلى تقييد الرقم. لا تستخدمها للإرسال الجماعي أو الرسائل المزعجة.
